Attendance

          
In-class rows used the rotating one-time code. Remote rows carry an external token. Flags mark shared devices, a second device, both modes, a late code, or a subnet mismatch.

          

            
            
            
          

          

        

      


      

        

          
Sound beacon

          
Play this on the laptop speakers, not headphones. Many laptops fade out above about 17 kHz, and phones often filter ultrasound unless noise processing is off.

          
          
          
          
          
          

          
          
          

            
            
            
            
          

          

          
Rotating code

          
The same HMAC window as the sound. It changes with the token. A phone can scan it or type it. Campus subnet is checked only when ZOOMODLE_ALLOWED_SUBNETS is set.

Anti-relay

          
The code is an HMAC over this room's key. It is valid for the current window and one grace window. Each device can redeem a code once, so a recording shared a few seconds later fails, and a second phone that replays the same code is rejected.
