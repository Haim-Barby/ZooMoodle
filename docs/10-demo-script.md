# Demo script (about 10 minutes)

A script and checklist for the owner. Not yet performed.

**Before class:** open the Render HTTPS URL (or a cloudflared URL) on the laptop, have the lecturer key from `~/.zoomoodle/lecturer-key.txt` (local) or the Render dashboard, a roster CSV, a homework file, and two phones — one on the campus Wi-Fi, one on cellular.

| Minute | Who | Do | Pass looks like |
| --- | --- | --- | --- |
| 0:00 | Lecturer | Paste the key. | "שלום טום יניב, השבוע שבוע 4 בקורס מערכות נוירונים". |
| 0:40 | Lecturer | Open a lesson, import the roster. | Join QR and the flickering barcode on screen. |
| 1:20 | Phone A (campus Wi-Fi) | Scan the join QR → name → בכיתה → hold on the barcode 2 s → area. | ✓ "ברוך הבא ‹name›"; dashboard: 1 in class, area on the map. |
| 2:40 | Phone B (cellular) | Same name list → בכיתה. | Refused: not on the university network. |
| 3:10 | Phone B | Point at a screenshot of the barcode (if on Wi-Fi). | Rejected as a still image. |
| 3:40 | Phone B | Choose מרחוק. | ✓ remote; dashboard: 1 remote. |
| 4:20 | Phone B on Wi-Fi | Pick Phone A's name in class. | Both phones get the re-pick popup. Pick the same name again → code step; dashboard shows the code ("מצב הדגמה – המייל לא נשלח") or it arrives by e-mail. Phone A types it → keeps the name; Phone B → lecturer. |
| 6:00 | Lecturer | Press "דחה" on Phone B's claim. | Phone B shows "לא אושר". |
| 6:30 | Lecturer / Phone A | Open a poll; answer; send a note and a question. | Live counts, the note, the question with votes. |
| 7:30 | Lecturer | Upload homework. | Phone A downloads it. |
| 8:15 | Lecturer | Write or generate the summary (key optional). | It appears on Phone A. The key field is empty afterwards. |
| 9:15 | Lecturer | Export CSV/Excel. | Name, mode, state, area, time — no email, no id. |

## Checklist

- [ ] Greeting shown after the key.
- [ ] In class needed both the campus Wi-Fi and the live scan.
- [ ] Off-campus and screenshot attempts failed.
- [ ] Duplicate name went popup → code → lecturer.
- [ ] Poll, note, question, homework, summary worked from the phone.
- [ ] Export has no email or id; no key in any screenshot or commit.
- [ ] Results written in the tools report table.
